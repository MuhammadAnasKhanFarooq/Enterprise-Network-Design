# Enterprise Network Design

A third-semester academic networking project developed using Cisco Packet Tracer.

The project was created to practice the design and configuration of a departmental network with VLAN segmentation, dynamic IP addressing, routing, device security, and configuration backup.

## Project Overview

The network connects multiple departments, including:

- IT
- Finance
- Computer Science
- Management

The topology was designed to provide organized communication between departments while keeping network traffic logically separated.

## Features Implemented

- VLAN creation and configuration
- Access port assignment
- Trunk port configuration
- DHCP configuration
- Dynamic IP address assignment
- RIP routing
- Inter-VLAN communication
- Router and switch hostname configuration
- Console and VTY password configuration
- Local user authentication
- Enable password and enable secret
- TFTP configuration backup
- Network connectivity testing using ping

## Network Design

The project uses a hierarchical network design with:

- Core layer
- Distribution layer
- Access layer

A hybrid topology was used, combining departmental star topologies with interconnected routers.

## Technologies & Tools

- Cisco Packet Tracer
- Cisco IOS
- VLANs

- Inter-VLAN Routing

## Project File

The main Packet Tracer simulation is available in:

`enterprise-network-design.pkt`

## How to Run

1. Install Cisco Packet Tracer.
2. Download or clone this repository.
3. Open `enterprise-network-design.pkt`.
4. Wait for all devices and connections to initialize.
5. Inspect the routers, switches, VLANs, and end devices.
6. Use ping or Cisco IOS commands to verify connectivity and configurations.

## Project Background

This was developed as a group academic project during the third semester of BS Information Technology for the Computer Communication and Networking course.

The project was created for practical learning of network design, configuration, routing, VLANs, DHCP, and network troubleshooting.

AI-assisted support was used for parts of the learning and project development process.
